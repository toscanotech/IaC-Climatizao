# I&C Engenharia e Soluções em Climatização

Primeiro esboço de uma **One Page responsiva**, desenvolvido pela ToscanoTech.

## Publicação na Vercel

1. Em https://vercel.com/new, escolha **Import Git Repository**.
2. Selecione `toscanotech/IaC-Climatizao`.
3. Se solicitado, use **Framework Preset: Other**.
4. **Root Directory:** `./`.
5. **Build Command:** deixe vazio. **Output Directory:** deixe vazio.
6. Clique em **Deploy**.

O projeto é HTML estático, sem dependências ou variáveis de ambiente.
